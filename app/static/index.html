Đọc theo file SRT (khớp thời gian phụ đề)

Mỗi câu được đọc đúng mốc thời gian trong SRT. Câu dài sẽ tự tăng tốc để vừa khung, khoảng trống được giữ im lặng. Kết quả là 1 file WAV khớp với video.

Tích hợp Local API (Dành cho Lập trình viên & Tool Automation)

Gọi trực tiếp API từ Python, Node.js hoặc cURL tại máy chủ nội bộ:

curl -X POST "http://127.0.0.1:8001/api/tts/generate" \
  -H "Content-Type: application/json" \
  -d '{"text": "Chào mừng đến với Xteam Voice Studio!", "voice_id": "north_male_news_1", "speed": 1.0}'

Tích hợp API cho lập trình viên & AI Agent

Ví dụ gọi nhanh từ script hoặc các công cụ tự động hóa.

Ví dụ cURL: 
curl -X POST "http://127.0.0.1:8001/api/tts/generate" \
  -H "Content-Type: application/json" \
  -d '{"text": "Xin chào!", "voice_id": "north_male_news_1"}'
Ví dụ Python requests: 
import requests
r = requests.post("http://127.0.0.1:8001/api/tts/generate", json={"text": "Xin chào!", "voice_id": "Minh Đức"})
open("output.wav", "wb").write(r.content)
